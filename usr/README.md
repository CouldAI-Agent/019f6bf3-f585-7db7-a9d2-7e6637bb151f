# Kitchen by Deepu Pahadi

A modern, responsive kitchen management application built with Flutter.

## Overview
Kitchen by Deepu Pahadi provides a comprehensive suite of tools for managing daily kitchen operations. Whether you are running a home kitchen, a small cafe, or a professional restaurant, this app helps you stay organized with recipes, inventory, and staff tasks.

## Features
- **Dashboard Overview**: Get a quick glance at low stock items, today's specials, and pending prep tasks.
- **Recipe Management**: Store, organize, and view detailed recipes with ingredients and instructions.
- **Inventory Tracking**: Monitor stock levels, track unit costs, and receive alerts for items running low.
- **Responsive Design**: Seamlessly transitions between mobile, tablet, and desktop layouts.
- **Dark Mode Support**: A beautiful, accessible UI that respects system theme preferences.

## Tech Stack
- Framework: Flutter
- UI Components: Material Design 3
- State Management: StatefulWidgets
- Responsive Layout: LayoutBuilder & MediaQuery

## Getting Started

1. Ensure you have the Flutter SDK installed (version 3.7.2 or higher).
2. Clone this repository.
3. Run `flutter pub get` to install dependencies.
4. Run the app using `flutter run` on your preferred device or emulator.
